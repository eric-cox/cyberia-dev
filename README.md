# Cyberia

**Cyberia – search of salvation in Siberian wastelands**

Пиксельное выживание в киберпанк-сеттинге сибирских пустошей.

## О игре

Далёкое будущее. Развитие электроники привело к появлению всевозможных андроидов, которые заменили ручной труд людей. Все задачи перешли на ИИ, и человечеству осталось только морально разлагаться. Экология катастрофически ухудшилась — находиться вне дома опасно для здоровья, атмосфера потихоньку убивает организм.

Сибирские пустоши замёрзли — климатические системы вышли из-под контроля, или корпорации так решили. Неоновые вывески пробиваются сквозь метель, голограммы мерцают над мусором, киберимпланты искрят на морозе.

Вы — Анахронизм, тот, кто отказался от комфорта виртуальной реальности и вышел в мёртвый город. Ваша цель — выжить, собирая артефакты и сражаясь с мутантами и сломанными роботами.

## Особенности

- **Процедурная генерация** городского района с улицами, зданиями и переулками
- **Система тепла и жизни** — пурга съедает тепло, мороз выедает жизнь
- **6 типов врагов** — от гигантских крыс до осознанного ИИ-бота
- **Система экипировки** — одежда защищает от холода, оружие помогает выжить
- **Многослойный рендеринг** улиц с неоновыми вывесками, мусором и разлитым маслом
- **Динамическая погода** — ветер, метель, сажепад

## Управление

- **WASD / Стрелки** — движение
- **SPACE / ЛКМ** — атака
- **TAB / I** — схрон (инвентарь)
- **M** — вкл/выкл звук
- **R** — перезарядка дробовика
- **Delete** — самоубийство

## Технологии

- React 18 + TypeScript
- Vite
- Canvas 2D для рендеринга
- Web Audio API для звуков
- Tailwind CSS для UI
