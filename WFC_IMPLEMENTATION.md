# Отчёт о реализации WFC генерации города

## Что сделано

### 1. Создан новый модуль `world/CityGenerator.js`
- Реализован базовый алгоритм Wave Function Collapse
- Определены 5 типов тайлов: WALL, ROAD, SIDEWALK, HOUSE, STALL
- Заданы правила соседства для каждого типа тайла
- Реализована функция предзаполнения границ (стена по краям карты)
- Реализована генерация дорожной сети с учётом ограничений:
  - Ширина дорог: 2-6 тайлов
  - Минимальное расстояние между параллельными дорогами: 12 тайлов
- Реализован основной цикл WFC:
  - Выбор ячейки с минимальной энтропией
  - Сворачивание к одному состоянию
  - Распространение ограничений (propagation)

### 2. Обновлён `world/WorldGen.js`
- Удалена старая система генерации (streetNetwork, buildings, objects)
- Интегрирован новый `CityGenerator`
- Упрощена функция `generateWorld` до 4 этапов:
  1. Генерация города с WFC
  2. Постобработка (TODO)
  3. Генерация мусора и масла
  4. Финализация (стартовая зона, индекс проходимых ячеек)

### 3. Обновлён `render/TerrainPainter.js`
- Удалена зависимость от `StreetRenderer`
- Добавлена простая отрисовка дорог
- Упрощён единый проход по всем тайлам

### 4. Удалены старые файлы
- `world/streetNetwork.js` (571 строка)
- `render/StreetRenderer.js` (67 строк)

### 5. Обновлена документация
- `WORLD.md` — описание нового алгоритма WFC
- `ARCHITECTURE.md` — новая архитектура генерации

## Проблемы и решения

### Проблема 1: WFC не учитывает глобальные ограничения
**Решение**: Добавлена предварительная генерация дорожной сети до WFC.

### Проблема 2: Дублирование данных
**Решение**: Удалён `streetNetwork`, данные хранятся только в `WorldMap.tiles`.

### Проблема 3: Сложная отрисовка
**Решение**: Упрощён `TerrainPainter` — один проход вместо нескольких слоёв.
